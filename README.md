# IT Support Practical Portfolio

## Overview

This repository documents my personal Windows Server home lab, built to practise foundational IT support and troubleshooting skills relevant to entry-level Service Desk and IT Support roles.

## Lab Environment

- VirtualBox virtual machine
- Windows Server
- Active Directory user and group administration
- DNS and hostname resolution checks
- IP configuration and network connectivity testing
- Event Viewer and command-line diagnostics

## Practical Tasks

### 1. Active Directory
- Viewed and managed user account settings in a lab environment.
- Practised password reset and account-status checks.
- Inspected Helpdesk group membership.
- Ran a selected `dcdiag` diagnostic test and recorded the result.

### 2. DNS and Networking
- Tested DNS name resolution and hostname identification.
- Reviewed IP configuration using Windows networking tools.
- Tested network connectivity and recorded the results.

### 3. Troubleshooting
- Inspected Windows Event Viewer logs for a Network List Service error.
- Practised gathering diagnostic evidence and recording observations.
- Documented test results without assuming that an issue was resolved unless verified.
